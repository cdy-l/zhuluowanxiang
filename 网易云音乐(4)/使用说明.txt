1.下载需要的第3方库:
	终端运行下面3个代码,依次输入完命令后回车执行(运行完一个再运行下一个):
						pip install pyexecjs    
						pip install requests
						pip install jsonpath

2.安装需要的js解释器:
				通过电脑文件夹双击打开(不要通过pycharm打开)node-v20.18.0-x64.mis这个安装文件,
				一路next下一步(只需要勾选第1个接受许可选项,中间不需要再勾选任何选项),完成即可
				安装完成后重启下电脑再运行代码
3.使用:
		首先在终端输入歌曲名称(例如:绅士) 回车,
		然后找到这首歌在网易云链接上的歌曲id(例如绅士歌曲的id:32192436)回车,这首歌就会下载到项目文件夹里的网易云音乐文件夹里.
